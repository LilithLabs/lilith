# Security

Lilith is a set of instructions and templates that run inside Claude. Most of its discipline
is enforced by the model following written rules, not by a sandbox. The honest boundary of
what that does and does not guarantee is in
[`docs/security-and-limitations.md`](docs/security-and-limitations.md) -- please read it
before relying on any isolation or locality claim.

To report a security concern, email **lilith@lilithlabs.ai**. Please do not open a public
issue for anything that could put users' data at risk.
